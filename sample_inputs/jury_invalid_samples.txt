================================================================
  MiniLang Compiler — 20 INVALID Sample Programs (Jury / Viva Demo)
================================================================
Each program demonstrates a specific kind of compiler error.
The error type is listed; copy each program into the editor and
press Compile to see the message in the Errors tab.
================================================================


----------------------------------------------------------------
SAMPLE 1 — LEXICAL: Invalid symbol '@'
Expected: Line 2: Invalid symbol '@'
----------------------------------------------------------------

PRINT(a);

----------------------------------------------------------------
